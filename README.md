# SEhViewer

一个运行在 iOS 上的 E-Hentai / ExHentai 阅读器，基于 [Scripting](https://scripting.fun) 应用构建，界面采用 iOS 26 风格的 Liquid Glass 液态玻璃材质。无需越狱，无需电脑，手机装好就能看。

> 本项目基于 JSEhViewer 修改而来，针对 2026 年新版站点结构做了大量适配，并重写了整套界面。

## 功能特性

### 📖 浏览
- **推荐页**：登录后拉取 `/home.php` 个性化推荐；未登录自动回退到热门榜单
- 最新发布、热门、我的订阅、收藏夹、Toplist、最新上传等多种列表
- **分类筛选**：内置 E-Hentai 全部 10 个分类，可任意组合
- 列表卡片显示封面、标题、页数、大小、**语言徽标**（language 标签自动识别）、**AI 内容紫色徽标**

### 🔍 搜索
- 标题 / 作者 / 标签关键词搜索，原生支持 `namespace:tag` 语法（如 `female:big breasts`、`artist:xxx`）
- **搜索历史**：本地保存最近 20 条，支持单条删除、一键全部删除，点击历史词直接再搜
- 详情页的标签可直接点击，跳转全屏结果页继续搜同标签

### 🖼️ 阅读器
- **单张模式**：左右滑动或点击屏幕左右边缘翻页，方向（左→右 / 右→左）可自定义
- **拼接滚动模式**：整本像长图一样连续滚动（Webtoon 式），支持横向 / 纵向拼接，右翻书方向自动镜像
- 翻到末尾**自动加载后续图片**，长本子不用手动翻页
- 预加载 ±1 页、请求序号防竞态，翻页基本无白屏
- **动态图识别**：检测到 GIF 自动切换单张模式并提示
- **长按任意图片保存到相册**，底部栏也有一键保存

### ⬇️ 下载
- **整本打包**：一键下载全部图片并打包成 zip，弹出系统分享菜单，可存文件 / 分享；下载过程可随时取消
- 单张保存：任意页面直接存入系统相册

### 🍪 Cookie 与登录
- 支持表站（e-hentai.org）免登录浏览，里站（exhentai.org）需登录
- 配套浏览器脚本（`browser.tsx` / userscript）：在 Safari 打开 E-Hentai 页面时，左下角悬浮按钮一键抓取 Cookie 写入本地文件，app 内"从浏览器导入"即可完成登录
- Cookie 仅保存在本机（app 本地存储 / 浏览器文件），**不会上传到任何服务器**
- 设置页可随时清除本地 Cookie、查看登录状态

### 🎨 界面与体验
- 全界面 **Liquid Glass 液态玻璃**材质，深浅色自适应（跟随系统 / 浅色 / 深色）
- 图片磁盘缓存：列表缩略图、阅读页大图二次进入秒开；清理缓存后封面自动恢复，无需重启
- 弱网友好：请求超时重试、Cloudflare 挑战检测、缩略图错峰加载

## 安装

1. 在 iPhone / iPad 上安装 [Scripting](https://scripting.fun)（App Store）
2. 将本仓库 `scripts/SEhViewer/` 目录放入 Scripting 的脚本目录
3. 打开 Scripting，运行 SEhViewer 项目即可

### 使用提示

- 第一次打开即可浏览表站（无需登录）
- 想进里站：先在 Safari 登录 E-Hentai 账号，用配套脚本抓取 Cookie，再回 app 设置页"从浏览器导入"
- 阅读方向、翻页方式、左右边缘点击动作都可在阅读器内 / 设置页调整

## 技术亮点

- **2026 新版站点适配**：重写列表 / 详情 / 图片页解析，兼容新版 sprite 精灵图、新评论结构、新收藏统计
- **Sprite 精灵图渲染**：站点缩略图精灵图按格子精确裁剪，同一精灵图 20 张缩略图只下载一次
- **三层缓存**：内存缓存（URL→Promise 去重）+ 磁盘图片缓存 + 精灵图缓存上限清理，兼顾速度与内存
- **阅读器手势体系**：无遮罩层实现点击翻页 / 滑动翻页，避免 overlay 干扰图片加载
- **导航架构**：详情页、阅读器、标签搜索结果全部用全屏 present 模式，返回逻辑稳定可靠
